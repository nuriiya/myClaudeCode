## 21:58 Bug 修复：需求澄清 Agent 循环提问同一问题

### 根因（三层）
1. **前端 onDone 全局 find**：模型本次回复无 QA 结构时，`[...msgs].reverse().find(m => m.meta?.qa)` 回退找到历史旧问题重新弹出 → 用户被迫重复回答同一问题（用户复现数据证实：首问后模型两次输出坏格式 ` ```j `，前端两次重弹首问）。
2. **后端 extractQA 脆弱**：`lastIndexOf('{"question"')` + `JSON.parse(text.slice(idx))`，模型输出带空格/缩进/markdown 围栏/尾部冗余时解析失败 → 需求澄清无法推进。
3. **req_state 漏记**：`qa.dimension` 缺失时 asked 不记录、回答不记录 → 系统提示词无已收集信息 → 模型失忆重复提问；回答记录 `!req.dimensions[last.dimension]` 丢弃重复回答。

### 修复内容
- `AgentManager.js`：新增 `extractJsonObject`（括号配对法，容错空格/围栏/尾部冗余），重写 `extractQA/extractDocReady`；提问/回答记录改为 dimension 缺失兜底「一般」、同问题去重、回答覆盖式；新增**格式自愈机制**（坏格式打 `lastFormatError` 标记 → 下一轮注入「格式修复提示」）。
- `store.ts`：onDone 改为只检查最后一条非错误 assistant 消息，不再全局回退。
- `requirement.md`：强化约束（dimension 必填、JSON 独占一行、禁围栏、禁止重复提问）。
- 新增测试：`scripts/unit-parse-test.mjs`（12 项解析容错）、`scripts/mock-broken.mjs` + `scripts/self-heal-test.mjs`（8 项自愈链路）。

### 验证

## 22:50 修复代码生成 0 文件 + 新增自定义 workfolder

  - `parseCodegen` 增强为三级 fallback：① FILE_START/FILE_END 协议 ② markdown 代码块带路径(```js:path) ③ 标题+代码块组合
  - `stripCodegenBlocks` 同步更新剥离逻辑
  - `maxTokens` 从 16000 改为 8192（DeepSeek API 安全上限）
  - 0 文件时增加诊断信息（区分空响应 vs 格式不匹配）
  - 新增 codegen 格式自愈机制（`lastCodegenEmpty` 标记 → 下一轮注入格式提醒）
  - `buildSystemPrompt` 和 `runCodegen` 支持自定义 workfolder 路径
- **`codegen.md`**：增强输出规范，加入完整格式示例
